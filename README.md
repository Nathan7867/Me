# Bet Finance Demo

A modern finance application for managing betting and financial transactions.

## Project Structure

```
bet-finance-demo/
├─ apps/
│  └─ frontend/
│     ├─ Dockerfile
│     ├─ index.html
│     └─ src/
├─ package.json
└─ README.md
```

## Getting Started

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Build for production: `npm run build`

## Features

- Modern finance dashboard
- Betting management system
- Real-time updates
- Responsive design

## Technologies

- React/Vue.js
- Node.js
- Docker
- Tailwind CSS
